# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.2.0](changelog/0.2.x/0.2.0.md) — 2026-11-15 · ⚠️ Breaking

Leaner tariff replies with limit-sized pages, a code-prefix search filter, ten-digit heading lookup, schema-advertised input patterns, verified General Note 3(b) editions, and a published usitc-tariffs-guide agent skill. Node IDs and cursors from 0.1.x are rejected, and several output fields are removed.

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-25

Resolve published tariff hierarchy and Chapter 99 evidence while retaining legal uncertainty.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-25

Search U.S. tariff schedules and inspect published duty evidence with six read-only tools.
