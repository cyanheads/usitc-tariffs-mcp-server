# 0.1.1 — 2026-10-25

## Added

- **HTS navigation** — search descriptions and code prefixes, inspect complete heading ancestry, and browse chapter subtrees with published rate-line and statistical-line counts.
- **Base duty lookup** — retrieve General, Special, and Column 2 cells with inheritance provenance; preserve unknown country membership and preference qualification.
- **Chapter 99 research** — inspect partial additional-duty candidates, evidence, and complete supporting passages; empty results never establish clearance or current legal applicability.
- **Reference tables** — decode identifier formats, edition-pinned program symbols and quantity units, chapter labels, and published release metadata.
- **Source continuity** — retain provenance and matching response surfaces with argument-bound pagination, explicit continuation, and edition-change detection.
- **Installation** — stdio and Streamable HTTP, npm, Docker, Claude Desktop bundles, and Claude Code/Codex plugins; no upstream account or API key required.
