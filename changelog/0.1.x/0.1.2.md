- **Published subchapter titles** remain separate heading metadata and group following chapter entries without becoming legal ancestors ([#5](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/5)).
- **Sentence-final code tokens** retain research pointers before punctuation without accepting malformed identifier continuations ([#6](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/6)).
- **Numbered following lists** link directly owned code entries to their governing Chapter 99 heading, with complete independent passage follow-ups; descriptive entries remain qualified context ([#7](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/7)).
