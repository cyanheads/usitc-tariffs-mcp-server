# 0.2.0 — 2026-11-15

## Added

- **`usitc-tariffs-guide` agent skill** in `skills/`, served over MCP as `skill://usitc-tariffs-guide/SKILL.md` with the `io.modelcontextprotocol/skills` extension capability, and shipped in the npm package, Docker image, MCPB bundle and plugins.
- **`usitc_search_hts` `codePrefix`** keeps matches under a chapter or 4/6/8-digit code before counting and paging, echoes the canonical prefix, and binds it to the cursor ([#15](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/15)).
- **`usitc_get_heading` accepts ten-digit codes**, returning that node and its descendants with a `parentFollowUp` into the four-digit heading ([#17](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/17)).
- **Input patterns** for `code`, `candidateCode`, `countryCode`, `chapter` and `query` are advertised in `tools/list` ([#17](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/17)).
- **`verifiedEditions`** (`2026HTSRev22`, `2026HTSRev23`) lets `usitc_lookup_duty_rate` answer General Note 3(b) `listed`/`not_listed` with `editionMatches: true`, provenance staying on the reviewed `2026HTSRev21`. `scripts/verify-general-note-3.ts` checks further editions ([#13](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/13)).

## Changed

- **Node IDs and cursors** use short digests: node IDs are `<release>:<12 hex>:<ordinal>`, snapshot IDs and cursor digests 16 hex. Node IDs and cursors from 0.1.x return `invalid_cursor`; repeat the call without `nodeId`/`cursor` ([#10](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/10)).
- **`limit` is the only page bound**: defaults are 25 (search, browse, reference) and 10 (heading, additional duties), and values above 100 clamp to 100 with the notice `Requested limit <n> was clamped to the 100-item page cap.` ([#12](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/12)).
- **Reply payloads** render `content[]` JSON as a single-line fence, carry `usitc_list_reference` `spi`/`units` provenance once in a page `decoder`, and shorten `coverage.sourceDigest` to 16 hex; miss replies keep `guidance` without a duplicate notice ([#10](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/10)).
- **`usitc_check_additional_duties`** returns its summary fields only on the first candidates page, carries one page-level `sourceUrl`, and states "No candidate list, empty or not, establishes that no additional duty applies." in `notices` on every page ([#10](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/10)).
- **Malformed code, chapter, `candidateCode` and country syntax** fails at the schema as `invalid_arguments` (-32602) instead of a domain reason (-32007) ([#17](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/17)).
- **`releaseList`** is read only when the current release name changes: a cold read makes 4 requests, an uncached read inside the metadata window 2, and one after it 3 ([#14](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/14)).
- **Framework adoption** syncs the framework skills, scripts and changelog template; the Dockerfile copies `skills/` into the image.

## Removed

- **`page.budgetLimited`** on every paginated tool, and the 24 KB reply budget with its `reply_item_too_large` failure ([#12](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/12)).
- **Node identity fields**: search-row `nodeId`, heading `sections[].nodeId`, and `sourceNodeId`/`sourceHtsno`/`sourceFollowUp` on `published` rate columns (inherited columns keep them) ([#10](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/10)).
- **`usitc_lookup_duty_rate`** top-level `resolvedRates` (`row.resolvedRates` is unchanged) and its enrichment `notice`/`totalCount` ([#10](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/10)).
- **`usitc_check_additional_duties`** `coverage.limitations`, the summary fields on pages after the first candidates page, per-candidate `sourceUrl`, `passageId` and `notesPage.nextNoteCursor` ([#10](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/10)).
- **`usitc_list_reference` `spi`/`units`** per-item `citation`, `sourceUrl`, `sourceEdition`, `conditionality` and `qualificationNotice`, now one page `decoder` ([#10](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/10)).

## Fixed

- **Evidence codes** `sourceCode` and `matchedCode` use the dotted canonical form on every evidence kind and view ([#16](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/16)).
- **Non-ASCII country input** that `toUpperCase()` mapped onto an assigned ISO code (`ß`→SS, `ﬁ`→FI, `ıt`→IT, `ſe`→SE) is rejected instead of answering for another country ([#17](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/17)).
- **Whitespace-only `query`** returns `invalid_arguments` instead of a reasonless error ([#17](https://github.com/cyanheads/usitc-tariffs-mcp-server/issues/17)).
- **Ancestor-scope footnote evidence** omits `matchLevel`.
- **Additional-duties base miss** no longer offers an unmapped-view follow-up that misses again.
- **The code-length error** reads "8 or 10 digits".
